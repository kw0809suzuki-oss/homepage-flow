Re-entry Packet Lifecycle v0
2026-10-07

SCOPE
Re-entry Packet boundary only.
AI Entry and Execution OS are intentionally unchanged.

PURPOSE
Carry a return route during a temporary branch without turning the route into a control command.

LIFECYCLE
1. BRANCH
   A -> B
   markReturnPoint() captures A once with concrete references.
   Deeper B -> C -> D does not overwrite A.

2. RETURN
   B/C/D -> A'
   completeReturn() requires a non-empty A' coordinate.
   On successful return, the Return Point is consumed.
   This is re-entry with new information, not rollback.

3. PROMOTE
   If B becomes the explicit main line, promoteBranch() discards the old A Return Point.
   No automatic inference decides promotion.

STANCE
observed + observed -> observed
observed + inferred -> inferred
anything + unknown -> unknown
