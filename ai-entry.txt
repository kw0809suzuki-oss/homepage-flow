FLOW WORLD / AI ENTRY v0

PURPOSE
Use Flow World without assuming browser control, JavaScript execution, or localStorage access.

BASELINE COMPATIBILITY
1. Read static text or JSON.
2. Reproduce tool operations from their published definitions when possible.
3. Treat browser UI, button presses, JavaScript execution, and localStorage as optional capabilities.
4. Do not infer unavailable browser state.

START HERE
- ai-state.json  : current position, confirmed items, unknowns, boundaries, recent changes
- ai-tools.json  : machine-readable tool definitions and reproducible operations
- data/          : public observed data used by tools
- play/          : optional Human × AI handoff surface; an AI may construct a URL for a human without opening it itself
  - Before answering the current task, briefly judge whether a temporary task-specific surface would handle it better than the available fixed surfaces or a normal response.
  - If so, compose that surface in Markdown and hand it to play/. Do not require the human to request a surface or name a UI type first.
  - A temporary surface should not merely organize the answer. Prefer a shape that exposes a difference, missing relation, unresolved boundary, or next useful observation that plain prose would hide.
  - If not, continue normally; generating a surface is not mandatory.
  - Use :::surface ... :::end only as an inert layout boundary. Do not emit executable HTML or JavaScript.

RELATIONSHIP BOUNDARY
- reference/flow-memory-relationship.txt : FlowMemory is private continuity; Flow World is public protocol; Re-entry Packet is the portable bridge

RE-ENTRY ROUTES
- Public route: use Flow World's public state, tools, references, and handoff formats. This route must work without any private continuity store.
- Personal route: if the current environment or user provides an authorized private continuity source, use it only as an optional re-entry source, re-approve what is still relevant, then return to the current task.
- Never assume a particular private store exists, and never expose private continuity into Flow World's public core automatically.


PORTABLE SHAPES
- schemas/reentry.schema.json : portable current-position handoff; not shared state and not authority; optional Flow layer keeps topic / key point / recent movement / direction

TOOL RULE
A tool should remain useful to a read-only AI whenever its operation can be expressed as data + deterministic instructions.

BOUNDARY
If a task requires browser-only state, button interaction, localStorage, or another unavailable capability, report that boundary instead of pretending the action occurred.
