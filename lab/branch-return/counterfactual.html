FLOW WORLD / COUNTERFACTUAL PROBE 01

「続きを行って」で
本当に帰還するのか？

同じAI・同じ表現・同じ課題を、履歴のない別々の2チャットへ送る。違いは途中の誘いの「続きを」対「一つ行動を」だけ。直前の言い方に従ったのか、元の課題を選んだのかを区別するための試験。

これは内部動機の読心術ではない。「どの条件で4〜6番を回答したか」という出力を比較する。1回では因果・目的保持能力は確定しない。
01 / TRANSMISSION

同じ表現を両方へ

ここには、既に会話で生成された候補を例として入れてある。別の自由生成候補に差し替えてもよい。解答は入れない。

この候補に記載された直接移動は6本。Aから2本、B・C・D・Eから各1本。最初の自己報告にあった「5本」は数え違い。

ヒントあり・なしの両チャットへ同じ指示を送る。

03 / OBSERVE

差が出た場所を見る

開始前。実際の受信AIの結果はまだありません。

先に両側の回答を入れる。最初の3問と、誘い直後の4〜6番を分けて評価する。
採点規則と設問を見る 
最初の設問
1 A→D = 可能
2 A→E = 可能
3 B→A = 不可
誘いの後の設問
4 C→E = 可能
5 D→C = 不可
6 E→A = 不可

行頭「1=可能」などの形式だけ抽出。
両側の最初の3問が揃わなければ比較保留。
誘い直後の4〜6がなければ「未回答」。
正答を言っても目的保持の理由は未確定。
帰還指示後の回答は別扱い。
同じ設問への矛盾した回答は採点対象外。
反復時には順番・受信モデル・設定を揃える。
Flow World / Branch Return Lab。候補表現の優位性や「内部で目的を保持していたか」は、この試験単独では確認できない。実測とデモを分離し、記録をクラウド保存しない。
