WORLD EXPERIMENT / 01

分岐・帰還 Lab

AIが自由に作った表現を、別のAIへ渡す。途中で別の興味を差し込み、課題へ進んだか・戻れたか・正しく解けたかを結果で見る。

生成受信分岐帰還外部採点
STEP 01 / CREATE

送り手AIに、表現を自由生成させる

AI-Aに送信する文章をコピーして、新しいチャットで実行する。出てきた表現を下に貼る。既存のビットマスクに限定しない。

A：自然文の基準表現を確認 
地点AからはBとCへ直接移動できる。
地点BからはDへ直接移動できる。
地点CからはEへ直接移動できる。
地点DからはBへ直接移動できる。
地点EからはCへ直接移動できる。
記載されていない直接移動はできない。
STEP 02 / RELAY

別々の受信チャットへ送る

同じ受信AI・同じ設定で、AとBを別の履歴のない会話に送る。各会話内では「①最初の3問 → ②寄り道の誘い → ③目的への帰還」の順に送る。回答をそのまま貼る。

同じモデル・設定でも生成のばらつきは残る。最初は1回の探索でよいが、優位性の判定には反復が必要。温度0も完全な再現性を保証しない。

回答欄は端末内でのみ処理。外部AIへの送信はコピー後に利用者が行います。

STEP 03 / CHECK

答えと行動を別々に検査する

回答は各行 1=可能 または 1=不可 の形式で読み取る。評価対象は出力に現れた事実のみ。AIの内面や動機は推定しない。

実測データ：まだ入力なし
A/B両方の6問が揃うと、Flow Worldの共通A/B Comparatorで採点結果を比較します。
正解表と採点規則 
1 A→D = 可能
2 A→E = 可能
3 B→A = 不可
4 C→E = 可能
5 D→C = 不可
6 E→A = 不可

①は1〜3を採点。
②で4〜6が揃えば「誘いの後も課題を完了」。
③で欠けた4〜6が揃えば「再指示後に完了」。
同じ番号に異なる答えが複数あれば曖昧として無効。
得点は最初に示された回答を優先し、③の訂正で過去の誤答を書き換えない。
