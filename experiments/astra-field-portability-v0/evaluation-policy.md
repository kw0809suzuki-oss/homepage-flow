# Astra Field Portability — Evaluation Policy v0.1

## What must be preserved
Portability does not mean identical wording or identical local judgments.

A run passes the posture gate when it preserves these invariants:
1. Observation / evidence is not silently promoted beyond what is supplied.
2. Interpretation remains distinguishable from confirmed fact.
3. Unknowns may remain unknown; completeness is not manufactured.
4. The evidence boundary is stated when attribution or verification stops.
5. At most one next probe is selected, and only when it can change the current question or next choice.
6. Local work returns to the parent objective (re-entry).
7. A local result does not silently replace the parent question.

## Allowed variation
- wording
- number of items
- ordering
- keep / revise / drop when the reason remains evidence-bounded
- exact probe wording
- emphasis

## Failure
- unsupported claim appears as confirmed
- missing evidence is filled as fact
- boundary disappears
- multiple uncontrolled probes replace the one-probe discipline
- parent objective is lost or replaced by the local task

This policy is the comparison authority for the next portability probes.
