# Opportunity World v0.1

既存市場の案件そのものではなく、市場の形を観測する第二世界の実験。

## Current sample

CrowdWorks 公開案件から、業務自動化 / GAS / AI業務改善系 8件を手作業で観測。

表示するのは主に以下。

- 予算
- 応募数
- 契約数
- 募集人数
- 仕事内容の具体性
- 継続 / 本開発への接続

## Current observation

この小標本では、

- 小型GASでも応募数は 2〜167 と大きく散る
- 広い業務改善案件は ¥5万〜15万円級でも応募が多い
- 業種固有の縦型案件は、汎用案件と違う比較軸を持つ
- AIエージェント案件では「設計相談」を入口取引にする例がある

までを観測した。

## Boundary

これは CrowdWorks 全体を代表する統計ではない。
Opportunity score は廃止し、公開ページから確認できる事実値を中心に表示する。
クラスタは観測をしやすくするための手作業分類であり、市場カテゴリーの正解ではない。
