# Opportunity World v0

既存市場の案件・商品・制度そのものを並べるのではなく、その上にある「歪み」を観測する第二世界の最小プロトタイプ。

## Parent question

既存市場の上に、新しい観測面・新しい単位・新しい参加方法を追加すると、別の市場世界を作れるか。

## Current observation unit

- 需要圧
- 供給薄さ
- 支払強度
- 継続性
- 実装可能性

## Boundary

data/opportunities.json の数値は UI / 構造確認用の sample data。
現時点では需要・優位性・収益性を示す Evidence ではない。

## Next

一つの公開市場だけを対象に、実データで

案件 → 需要クラスタ → 歪み → 元案件

まで降りられる観測面を作る。
