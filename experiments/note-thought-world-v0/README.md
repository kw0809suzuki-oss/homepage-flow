# note 思考世界観測所 v0

note.com 上で公開されている「個人OS」「AIとの自己観測」「人格・記憶」「独自理論」などを、人の評価ではなく **公開された思考の軌跡** として観測する実験ページ。

## 観測対象

- 個人OS / 人間OS / AI OS
- AIを介した自己観測
- 人格・記憶モデル
- 独自理論 / 世界モデル
- AIとの関係定義の変化
- 外部検証へ戻る動き

## 境界

このページは人物の心理状態・正常性・病理を評価しない。
「自己認知ループ」「妄想」等を第三者ラベルとして付けない。
公開記事に実際に現れた語・概念・時系列のみを整理する。

## v0

10件の公開note記事・アカウントを手作業で観測。
まずは「同じ言葉が別々の人に再出現しているか」「AIとの関係の定義がどう違うか」が見えることを確認する。
