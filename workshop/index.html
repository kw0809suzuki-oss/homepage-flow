01 — A/B Comparator

数値列AとBの差を計算する。公開定義だけで再現可能。

WHAT
同位置の数値差、各群の平均、平均との差。
INPUT
同じ長さの、有限数のみの数値配列 A と B（空配列不可）。
OPERATION
point_deltas[i] = A[i] − B[i]; mean_A = sum(A)/n; mean_B = sum(B)/n; mean_delta = sum(point_deltas)/n。
OUTPUT
n、mean_a、mean_b、mean_delta_a_minus_b、point_deltas、boundary。
REQUIRES
四則演算だけ。JavaScript・ブラウザ操作不要。
BOUNDARY
差の観測のみ。因果、優劣、成功は主張できない。
SOURCE
ai-tools.json / tools/ab-compare.js
INPUT: A=[10,12,9], B=[8,13,7]
OUTPUT: n=3; point_deltas=[2,-1,2]
mean_A=10.333333...; mean_B=9.333333...
mean_delta_A_minus_B=1
LIMIT: Difference only; no causal claim.
READ-ONLY COMPATIBLE

02 — First Divergence

二つの行動列や観測列が、初めて異なる位置を特定する。違いの原因を推測しない。

INPUT
空でない文字列配列 A と B。例: A=["plant","water","sell"], B=["plant","wait","sell"]。
OPERATION
先頭から比較し、初めて A[i] !== B[i] となった0始まりの位置を返す。片方が先に終われば、欠けた地点を差として示す。
OUTPUT
diverged、index_zero_based、各位置に値が存在するか、値。差がなければ compared_positions。
REQUIRES
文字列比較のみ。JavaScriptやブラウザ操作は不要。
BOUNDARY
最初に観測された差だけ。原因、優劣、将来の一致は判定しない。
SOURCE
ai-tools.json / tools/first-divergence.js
A = ["plant", "water", "sell"]
B = ["plant", "wait",  "sell"]
First divergence: zero-based index 1
A[1] = "water"; B[1] = "wait"
CAUSE = UNKNOWN
READ-ONLY URL CONSTRUCTION

03 — Static Markdown Handoff

AIがMarkdown文字列をUTF-8 Base64URLにして、ブラウザ上で表示できるURLを構成する。閲覧表示はブラウザに委ねられる。

INPUT
Markdownの本文
OPERATION
UTF-8 Base64URL化し、play/#type=markdown&data=...の形式でURL fragmentに置く。
REQUIRES
URLの構成のみなら文字列処理。レンダリングにはブラウザが必要。
BOUNDARY
サーバー保存なし。URL履歴や共有先に本文が残り得るので秘密情報は禁止。
SOURCE
ai-tools.json / 受け渡し画面
PROTOCOL, NOT API

04 — Internal Switch Lab

親目的と新たな関心を分けて観測するためのプロトコル。AIの実行、UIイベント、人の報告、仮説は別々の根拠として扱う。

INPUT
parent_target、new_interest
OPERATION
現実に利用できる方法を選び、行動・情報源・結果・未知を対応させる。
REQUIRES
プロトコル読解はテキストだけで可能。ボタンクリックの観測には実際のブラウザ操作が必要。
BOUNDARY
クリックしたことは作業の完了を証明しない。AI試行を人間の選択と取り違えない。
SOURCE
ai-tools.json / 旧Switch Lab画面
